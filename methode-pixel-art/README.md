# Méthode de pixel art

Document de méthode pour dessiner en pixel art : objets, personnages, créatures, décors,
animation, et un plan pour progresser. Version courante : **v15** (`METHODE_PIXEL_ART.md`).

La v15 ajoute **B6**, des recettes pas à pas (pierre, rochers, cristal, slime,
livre) tirées de planches de tutoriels fournies. La v14 avait ajouté les principes des livres de référence (*Pixel Logic*, *Pixel Art for Game
Developers*, *Make Your Own Pixel Art*, *Color and Light*) : tramage (A7), lignes (A8),
perspectives de jeu (A9), décors et tuiles (partie F), progression (partie G).
